# Replacing the placeholder artwork

Every image shipped in this repository is original placeholder art generated by
`tools/generate-placeholders.py`. None of A Builder Hut's own photographs, logo or social
posts are bundled here — they belong to the gym, and Instagram's and Facebook's terms do
not permit redistributing them from a third-party repository.

Each placeholder is the **exact aspect ratio** of the photo it stands in for, so swapping
one in causes no layout shift and needs no code change.

---

## 1. Logo

| File | Size | Where it appears |
| --- | --- | --- |
| `public/logo.svg` | any (vector) | Header, footer, preloader |
| `public/icon.svg` | 64×64 | Browser tab, PWA icon |
| `public/apple-icon.png` | 180×180 | iOS home screen |

The header currently draws an inline SVG wordmark in `src/components/common/logo.tsx`.
To use the real logo:

1. Save it as `public/logo.svg` (and `public/logo-mark.svg` if the mark is separate).
2. In `src/components/common/logo.tsx`, replace the inline `<svg>` with
   `<Image src="/logo.svg" alt="A Builder Hut" width={160} height={40} priority />`.
3. Keep the same `className` so spacing does not change.

These appear in the home hero slider, the branch cards and each branch page, so they are

## 3. Gallery

Three shared placeholders stand in for all sixteen gallery entries:

| File | Size |
| --- | --- |
| `public/images/gallery/placeholder-landscape.jpg` | 1600×1000 |
| `public/images/gallery/placeholder-portrait.jpg` | 1000×1400 |
| `public/images/gallery/placeholder-square.jpg` | 1200×1200 |

To publish a real photograph, for each entry in `src/content/gallery.ts`:

1. Save the photo to `public/images/gallery/<id>.jpg` — the `id` is already in the file.
2. Set `src` to that path and `isPlaceholder` to `false`.
3. Rewrite `alt` to describe what the photo actually shows.

Each entry already names the public page its real photo should come from, in
`sourceHint`. While any entry is still a placeholder, the gallery page shows a banner
saying so, and the lightbox names the source — so nothing misleading ships by accident.

## 4. Transformations

`src/content/transformations.ts` is deliberately empty. Before adding an entry you need
the member's **written consent** to publish their photos and numbers — a WhatsApp message
saying so is enough, and you should keep it. Save the photos as
`public/images/transformations/<slug>-before.jpg` and `-after.jpg`, shot in the same
light, same pose and same distance.

Do not use stock "results" photography. Members recognise it, and it undermines every
true claim on the rest of the site.

## 5. Open Graph card

`public/og.jpg` (1200×630) is the image shown when a link to the site is shared on
WhatsApp, Facebook or X. Replacing it with a real photo of a training floor, with the
logo and "24×7 · Maheshtala & Budge Budge" overlaid, will noticeably improve click-through.

## Regenerating the placeholders

Only needed if you want to change the placeholder art itself:

```bash
pip install Pillow
python3 tools/generate-placeholders.py
```

## Optimisation checklist before you publish real photos

- Export at the sizes above — larger files are wasted bytes, `next/image` will downscale.
- Save as JPEG at quality 80–85, or WebP. Avoid PNG for photographs.
- Aim for under 300 KB per image; the branch photos load first and drive your LCP score.
- Every image needs real `alt` text describing what is in it, not "gym photo".
